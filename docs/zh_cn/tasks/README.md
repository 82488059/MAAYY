| 文档 | 内容 |
| --- | --- |
| [一条龙](一条龙.md) | 可勾选步骤的总入口：买药→离开→炼药→钱袋→返回→找温→退出 |
| [自动买药](自动买药.md) | 货运买草药/枯茱萸，必要时先存放 |
| [存放原料](存放原料.md) | 原料入仓库，草药与枯茱萸留下 |
| [离开百业](离开百业.md) | 驻地退出到主界面 |
| [自动炼药](自动炼药.md) | 逍遥散循环炼药（需 Agent） |
| [自动天工](自动天工.md) | 天工道具 checkbox 多选合成（不耗体力） |
| [自动买钱](自动买钱.md) | 金丝钱袋与通宝（需 Agent） |
| [返回百业](返回百业.md) | 主界面回驻地 |
| [找温无双](找温无双.md) | 回驻地后走到温无双旁 |
| [退出游戏](退出游戏.md) | 一条龙找温后收尾（暂空转） |
| [无限集英](无限集英.md) | 循环点「集英」；齿轮填点后等待秒数（需 Agent） |
| [无限太极](无限太极.md) | 循环点「太极」；齿轮填点后等待秒数（需 Agent） |
| [每日号令](每日号令.md) | 菜单→门派→江湖号令，找「业火焚身」；没有则有刷新就点齐，无刷新视为已完成 |

旧任务细节（无限水井、地基模式、蔬菜/机关）见 [任务流程](../任务流程.md)。
