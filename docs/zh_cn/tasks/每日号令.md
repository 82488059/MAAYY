# 每日号令

本页说明界面任务「每日号令」。入口在 `assets/interface.json`，节点在 `assets/resource/pipeline/daily_order_task.json`，入口名 `每日号令`。

坐标与 ROI 均按控制器缩放到短边 720 后的 **1280×720** 图计算。流水线点刷新不强制 Agent；可选 Agent 动作 `号令_点刷新验标签`（`agent/daily_order_action.py`）仅作调试验签。不接入 [一条龙](一条龙.md)。

## 目标

入口会先 **定位当前步骤** 再接着跑（不必总从主界面开始）：观战中 / 继续 / 往生极乐 / 战斗中 / 匹配中 / 开始匹配 / 前往 / 业火 / 号令页 / 功能菜单 / 主菜单。

完整一圈仍是：菜单 → 门派 → 江湖号令 → 刷业火 → 前往匹配 → 战斗退出 → 回主界面再开号令；金色高亮时点领奖图标关结算；业火卡无刷新角标视为领完并点返回回主界面。勿用「参与觉障」文案判完成（未完成卡也有）。

## 前置

主界面能点右上角主菜单。模板用已有的 `storage/主菜单.png`，ROI `[1080, 0, 200, 90]`。战斗内门形模板 `daily_order/exit_door.png`（无「退出」文字，位置与离开百业不同）。

## 步骤

1. 功能菜单已开并能 OCR「门派」：不再点主菜单；否则点主菜单。
2. OCR 点「门派」→「江湖号令」→ 等左上「号」/「号令」。
3. 轮询「业火焚身」：已领完变灰 → 结束；金色高亮 → 点两个领奖图标并关结算；未完成则点进详情；**没有业火但页上还有刷新角标 → 一直点刷新再找，直到刷出业火或没有刷新为止**（不要因「刷一轮仍无」就提前结束）。
4. 点「业火焚身」→「前往」→「开始匹配」或已见「匹配中」。前往失败时查状态：有前往继续点，没有则再点业火。
5. 等「复活机会」→ 观战中则门形退出 / 或直接「继续」→ 往生极乐 → 继续；大厅先退匹配再返回主界面（不可在此直接点开始匹配，须重开号令查业火是否完成）。
6. 再从菜单进号令，领完业火为止。入口本身会定位当前步骤，不在 MFA 界面单独挂「战斗循环」。

## 失败出口 = 查找当前界面

号令任务 **不应硬失败**。凡原 `on_error → 结束失败` 的路径，一律视为软回收：

- `每日号令_结束失败` → 入口 `每日号令`（重新识别当前界面落在哪一步再接着跑）
- 入口自身定位不到时也再进 `每日号令`，不中止

真正允许停下来的情况只有：

1. 业火已领完（变灰、卡内无刷新）→ 回主 → `结束`
2. **号令页上 6 个刷新位都没有** `refresh_user` 角标（`检查刷新` 认不到，且 `无刷新收工` 确认仍在号令页）→ `结束`

## 刷新策略

- **有刷新、找不到业火 → 一直刷新**：`查找业火` → `检查刷新` → 点齐 `点刷新0`…`5` → 再 `查找业火`。
- **停刷条件**：号令页确认无刷新角标（见上）；不要用「刷了一轮仍无业火」结束。

## 前往失败

点业火进详情后点「前往」失败时，先 **查状态**（`号令_前往失败查状态`），按优先级：

1. 已见「开始匹配」→ 去点开始匹配  
2. 已见「匹配中 / 退出匹配」→ 接着等进战斗
3. 结算点完「继续」回到大厅且见「开始匹配」→ **直接再进**，不必先退大厅重开号令  
3. **仍有「前往」→ 继续点前往**（`号令_有前往续点`）  
4. **没有「前往」→ 再点业火**（`号令_见业火焚身`）  
5. 以上都没有 → 回入口 **查找当前界面**（不硬失败）

不要在「前往」还在时回点业火；也不要在「前往」已消失且已在匹配页时盲目点业火。

## 是否刷新成功

不要用「刷新图标还在不在」判断（点完图标常仍在）。应以 **卡内标签名是否变化** 为准。

标签相对刷新图标的位置，与「业火焚身」在业火卡内相对其刷新角标相同：以刷新框左上角为原点，标题 ROI 取偏移 `(-200, +24)`、大小 `130×42`（1280×720）。点前 / 点后各 OCR 一次该 ROI，读到的任务名不同即刷新成功。排除「单人」「多人」「特殊」等非标题字。

调试可用 Agent `号令_点刷新验标签` 按上述 ROI 验签；正式流水线 `点刷新0`…`5` 直接点 `refresh_user.png`。业火是否未完成看卡内 `refresh_yehuo`（相对标题 ROI 偏移 `[90,-55,180,110]`，阈值 `0.85`；过严会把未完成误判成领完）。

## 安全原则

- 没业火时先认刷新，有刷新就持续刷到刷出业火；没有刷新不要盲点。
- 战斗门形只用模板，不复用离开百业的「退出」OCR。
- 观战中出现后再点门形，避免战斗中途误退。

### 2026-10-14 软结束修补

- `号令_业火已领完`：原先 `on_error` 为空。已领完时「确认无刷新」And（需有 `refresh_yehuo`）永不命中 → 2500ms timeout → **硬 FAILED**。现 `on_error → 号令_领完回主界面`，按设计正常结束。
- `号令_等观战中`：原先 `next` 只等门形、`on_error` 仅点继续，失败经继续后等待又回到观战中 → **error handling loop → FAILED**。现 `next` 含门形/继续/往生，`on_error → 每日号令_结束失败` 重定位，禁止硬失败。
