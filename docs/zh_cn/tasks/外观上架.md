# 外观上架

本页说明界面任务「外观上架」。入口在 `assets/interface.json`，节点在 `assets/resource/pipeline/appear_list_task.json`，入口名 `外观上架`。无界面选项。可单独从主界面跑。不接入 [一条龙](一条龙.md)。

流水线协议见 [任务流水线协议](https://github.com/MaaXYZ/MaaFramework/blob/main/docs/zh_cn/3.1-%E4%BB%BB%E5%8A%A1%E6%B5%81%E6%B0%B4%E7%BA%BF%E5%8D%8F%E8%AE%AE.md)。坐标与 ROI 均按控制器缩放到短边 720 后的 **1280×720** 图计算。

> **实现状态**：流水线已落地。走到出售道具页后，空可寄售直接成功；有空位且第一格非空时只点第一个道具。右下同时出现「价格」和「寄售」即成功，不改价、不点寄售。以后填价再点寄售留在 `外观_上架占位`（`enabled: false`，不在成功链上）。单次上限 **6**。空格图 `assets/resource/image/appear/可寄售_空格.png` 待补。价格/寄售按钮 ROI 待截图再收。

## 目标

从主界面走到燕云商城的 **出售道具** 页：

**主菜单 → 商店 → 交易 → 出售道具**

主菜单展开后直接点格子「商店」，进入外观商城（顶栏：推荐 / 外观 / 精选 / 月卡 / 和鸣 / 福利 / **交易** / 充值）。

到达出售页之后：

1. 右侧是「暂无可寄售道具」，或可寄售区第一格对得上空格模板：直接成功，不点道具。
2. 左侧已是「出售道具 6/6」，或看不见「空闲」：直接成功，不点道具。外观最多同时上架 **6** 个（左侧「出售道具 x/6」）。
3. 左侧还有「空闲」，且第一格对不上空格模板：只点 **第一个道具**。右下同时出现「价格」和「寄售」即成功。不改价，不点寄售。

有可寄售道具 = 可寄售区第一格不是空的。用空格子模板比对，不 OCR 道具名，也不认数量「1」。

舟3 实测放入 3 件时：左侧仍是「出售道具 0/6」、六格全是「空闲」；右侧「可寄售」第一行 3 个图标。左侧「空闲」是上架槽空位，不是「没有可寄售」。

## 前置

- 人在 **主界面**（大世界），右上能点开主菜单。已停在商城、交易或出售页时，入口从当前页接着走。
- 短边 720；中文 OCR 已就绪。
- 主菜单模板复用 `storage/主菜单.png`。进不了出售页时，返回箭头复用 `medicine/返回.png`。
- 可寄售空格模板 `appear/可寄售_空格.png`（文件 `assets/resource/image/appear/可寄售_空格.png`）。只裁一个空格子，比 ROI 略小，不带图标。图还没放进仓库时，空仓靠「暂无可寄售道具」收工。缺图时取反会把「对不上模板」当成有货；空文案若也没认到，可能点到空的第一格。不要用 `image/empty.png` 充数。
- 成功路径没有新的自定义动作。失败收工复用 `打印失败节点`（`agent/debug_action.py`），因此和其它任务一样要带 Agent。Agent 没起来时这一步动作失败，任务仍然是失败。

## 步骤

起点：主界面。入口 `next` 按「已经走到哪」从后往前认，命中即从该步继续。

1. 已在出售页：`外观_认出售成功` 为 `And`，两个子识别都命中才进入分流。出售页 OCR「出售道具」，ROI `[160, 48, 740, 140]`（子页签和左侧标题「出售道具 0/6」）。可寄售区 OCR「暂无可寄售道具」「暂无可寄售」或「可寄售」，ROI `[900, 95, 360, 500]`（只盖右侧栏）。交易页只有子页签、还没有右侧「可寄售」时，`And` 不成立，改去点「出售道具」。
2. 已能看见子页签「出售道具」：OCR 点击，ROI `[400, 52, 500, 68]`（只盖页签行，约 y 52–120）。认不到则盲点 `(637, 97)`，只点一次。
3. 已在商城（顶栏有「交易」）：OCR `^交易$`，ROI `[360, 0, 480, 90]`。认不到或点了仍不见「出售道具」，盲点 `(590, 42)`，只点一次。
4. 功能菜单已开（菜单区内同时有「商店」和「包裹 / 不肝 / 培养」之一）：不再点主菜单，直接点「商店」。
5. 否则点右上角 **主菜单**（模板 `storage/主菜单.png`，ROI `[1080, 0, 200, 90]`，阈值 0.75）。模板没有时盲点 `(1180, 45)`，只点一次。
6. OCR 点菜单里的 **商店**（ROI `[740, 150, 480, 280]`）。认不到则先盲点 `(950, 270)`，仍进不了商城再盲点 `(848, 316)`。两处都只点一次。两个盲点之后仍不见「交易」，改盲点顶栏 `(590, 42)`。
7. 认不到出售页则失败收场：右上有返回箭头（`medicine/返回.png`，ROI `[1125, 0, 145, 68]`）就点一次，然后 `外观_结束失败`（`打印失败节点`）。不循环点返回。
8. 分流（`外观_分流可寄售`，同一张图上按顺序）：
   - OCR「暂无可寄售道具」/「暂无可寄售」/「无可寄售」（右侧栏 ROI 同上）→ 成功，不点。空格图还没放进来时，空仓靠这条。
   - OCR 标题「6/6」（ROI `[160, 100, 420, 80]`）→ 成功，不点。「0/6」对不上「6/6」。
   - 第一格模板匹配 `appear/可寄售_空格.png`，ROI `[988, 172, 72, 72]`，阈值 0.75 → 第一格是空的，成功，不点。ROI 只包第一格，后面的空格不算。
   - OCR 左侧「空闲」（ROI `[160, 150, 740, 500]`）→ 同一模板、同一 ROI，`inverse: true`。对不上空模板就是有道具，点第一格；模板仍对得上则成功，不点。
   - 以上都没有 → 成功，不点。
9. 点第一个道具：`外观_点第一个可寄售` 点击第一格中心 `(1024, 208)`，`max_hit` 为 1。然后 `外观_认上架面板` 为 `And`：右下 ROI `[640, 420, 620, 280]` 里同时 OCR「价格」和「寄售」（`^寄售$`，对不上标题「可寄售」），**只认不点**。两个都认到进 `外观_结束`。认不到也由点击节点的 `on_error` 停住成功，不改价、不点寄售。ROI 按「右下」先圈定，截图到了再收紧。

## 实机注记（1280×720）

燕云分身横屏。主菜单展开后，右侧功能格第二行左侧是「商店」（其上为「包裹」，其下为「不肝」）。点商店进入外观商城默认「推荐」。点「交易」后子页签为「外观推荐 / 珍品外观 / 武器外观 / 出售道具」。

出售页左右分开。左侧是已上架槽，标题「出售道具 x/6」，最多 6 格，空着写「空闲」。右侧是待上架，标题「可寄售」；空仓正文是「暂无可寄售道具」。放入 3 件后标题仍是「可寄售」，第一行 3 个图标，道具名看不见。右下有「交易记录」。

## 安全原则

- 不点「不肝」，不调用买钱节点。
- 到出售页即成功。空可寄售（空文案，或第一格对上空格模板）直接停，不点右侧空区。
- 左侧已满 6 个（「6/6」或看不见「空闲」）直接停。本版不把 6 格点满。
- 有空位且第一格非空时，只点可寄售 **第一个道具** 一次。不点数量「1」，不点「交易记录」，不点购买。
- 右下「价格」「寄售」只允许被认到。不改价，不点寄售。以后若要真正上架，在该面板里填价，再点「寄售」。
- 未知弹窗不盲点确定。导航失败最多点一次返回箭头，然后停住并失败。
- 还没到出售页不能结束。
