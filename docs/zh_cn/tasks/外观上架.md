# 外观上架

本页说明界面任务「外观上架」。入口在 `assets/interface.json`，节点在 `assets/resource/pipeline/appear_list_task.json`，入口名 `外观上架`。无界面选项。不接入 [一条龙](一条龙.md)。

坐标与 ROI 均按控制器缩放到短边 720 后的 **1280×720** 图计算。流水线协议见 [任务流水线协议](https://github.com/MaaXYZ/MaaFramework/blob/main/docs/zh_cn/3.1-%E4%BB%BB%E5%8A%A1%E6%B5%81%E6%B0%B4%E7%BA%BF%E5%8D%8F%E8%AE%AE.md)。

> **实现状态**：导航到「出售道具」页之后，仅在 **仍有空位且右侧有可寄售道具** 时点列表第一件。无可寄售或已满 6 个则直接成功。点开详情/上架面板就停，**不填价、不点确认**。填价和确认仍是 `enabled: false` 的占位。单次上限 **6**。

## 目标

从主界面走到燕云商城的 **出售道具** 页：

**主菜单 → 商店 → 交易 → 出售道具**

与 [自动买钱](自动买钱.md) 不同：买钱走「菜单 → **不肝** → 商店」（不肝顶栏里的商店，左侧是战斗养成）。本任务 **主菜单展开后直接点「商店」**，进的是外观商城（顶栏：推荐 / 外观 / 精选 / 月卡 / 和鸣 / 福利 / **交易** / 充值），不点「不肝」，也不复用 `钱袋_点不肝` / `钱袋_点商店`。

到达出售页后：

| 画面 | 动作 | 结果 |
| --- | --- | --- |
| 右侧是「暂无可寄售道具」 | 不点 | 成功 |
| 左侧已是「出售道具 6/6」，或看不见「空闲」 | 不点 | 成功 |
| 左侧还有「空闲」，且右侧有可寄售图标 | **只点第一件** | 若弹出详情/上架面板，认到就停；认不到也停。成功 |

舟3 实测放入 3 件时：左侧仍是「出售道具 0/6」、六格全是「空闲」；右侧「可寄售」第一行 3 个图标，每个数量 1，**道具名看不见**。所以第一件按图标坐标点，不按名字 OCR。

点完 **不填价、不点确认、不点上架按钮**。单次上限 6：x/6 是左侧已上架数，空格写「空闲」。有 3 件可寄售时左侧仍可以是 0/6。本版不把 6 格点满。

## 与自动买钱的差别

| 项 | 外观上架 | 自动买钱 |
| --- | --- | --- |
| 商店入口 | 主菜单格子「商店」 | 主菜单「不肝」再点顶栏「商店」 |
| 到达页 | 交易 → 出售道具 | 不肝商店的战斗养成 / 赛季追赶 |
| 成功 | 无货或无空位直接停；有空位且有货则点第一件后停 | 买完或库存/代币不足后回主界面 |
| 上架 / 购买 | 只点第一件图标；不填价、不确认 | 会点购买 |

## 前置

- 人在 **主界面**（大世界），右上能点开主菜单。已停在商城、交易或出售页时，入口会从当前页接着走，不必退回主界面。
- 短边 720；中文 OCR 已就绪。
- 主菜单模板复用 `storage/主菜单.png`。失败时若在全屏界面里，返回箭头复用 `medicine/返回.png`。不新增模板。
- 成功路径没有新的自定义动作。失败收工复用已有 `打印失败节点`（`agent/debug_action.py`），因此和其它任务一样要带 Agent。Agent 没起来时这一步动作失败，任务仍然是失败。

## 步骤

起点：主界面。入口 `next` 按「已经走到哪」从后往前认，命中即从该步继续。

1. 已在出售页（「出售道具」且「可寄售」或「暂无可寄售道具」）：进入下面的分流，不必再点页签。
2. 已能看见子页签「出售道具」：点它，再做第 1 步。
3. 已在商城（顶栏有「交易」）：点「交易」，再点「出售道具」。
4. 功能菜单已开（菜单区内同时有「商店」和「包裹 / 不肝 / 培养」之一）：不再点主菜单，直接点「商店」。
5. 否则点右上角 **主菜单**（模板，ROI `[1080, 0, 200, 90]`）。模板没有时盲点 `(1180, 45)`，只点一次。
6. OCR 点菜单里的 **商店**（ROI `[740, 150, 480, 280]`）。认不到则先盲点 `(950, 270)`，仍进不了商城再盲点 `(848, 316)`。两处都只点一次。两个盲点之后仍不见「交易」，改盲点顶栏 `(590, 42)`，不再回点商店。
7. OCR 点顶栏 **交易**（ROI `[360, 0, 480, 90]`，先整词「交易」，避免吃进「交易记录」）。点了仍不见「出售道具」，或 OCR 没点到，则盲点 `(590, 42)`（只点一次）。
8. OCR 点 **出售道具** 页签（ROI `[400, 52, 500, 68]`，只盖页签行，约 y 52–120；中心仍是 `(637, 97)`）。不把左侧标题「出售道具 0/6」算进点击区。认不到，或点了仍没有可寄售文案，则盲点 `(637, 97)`。
9. 判定已在出售页（见下）。认不到则失败收场：右上有返回箭头就点 **一次**，然后 `外观_结束失败`。不循环点返回。
10. 分流（`外观_分流可寄售`，同一张图上按顺序）：
    - OCR「暂无可寄售道具」→ 成功，不点。
    - OCR 标题「6/6」→ 成功，不点。不把「0/6」当成「6/6」。
    - OCR 左侧「空闲」→ 再看一次空文案，仍没有才点第一件。
    - 以上都没有 → 成功，不点。
11. 点第一件：坐标 `(1024, 208)`，只点一次。然后 OCR 详情/上架面板（「上架」「单价」「确认上架」等），**只认不点**。认到或 3 秒内认不到，都进 `外观_结束`。


占位节点画成虚线：它在流水线文件里，**不在**成功 `next` 上。点第一件不走这个占位。

## 成功条件

节点 `外观_认出售成功` 是 `And`，两个子识别都命中才进入分流（还不是任务结束）：

| 子识别 | 期望 | ROI |
| --- | --- | --- |
| 出售页 | OCR「出售道具」 | `[160, 48, 740, 140]`（子页签，以及左侧标题「出售道具 0/6」） |
| 可寄售区 | OCR「暂无可寄售道具」「暂无可寄售」或「可寄售」 | `[900, 95, 360, 500]`（只盖右侧栏，不盖左侧六格「空闲」） |

交易页只有子页签「出售道具」、还没有右侧「可寄售」时，`And` 不成立，会去点「出售道具」，不会提前成功。

分流用的另外两块：

| 判断 | 期望 | ROI | 接着 |
| --- | --- | --- | --- |
| 无货 | 「暂无可寄售道具」 | 同上右侧栏 | 成功，不点 |
| 无空位 | 「6/6」 | `[160, 100, 420, 80]` | 成功，不点 |
| 有空位 | 「空闲」 | `[160, 150, 740, 500]` | 再确认不是空文案后点第一件 |

左侧「空闲」表示还有空位，不是「没有可寄售」。有 3 件可寄售时六格仍全是「空闲」。道具名看不见，数量「1」也不拿来点。

点第一件之后，`外观_认上架面板` 在 `[200, 40, 1000, 640]` 里找「确认上架 / 立即上架 / 上架 / 单价 / 定价 / 寄售价 / 手续费」等。这些词还没有对应的实机截图，命中只说明面板出来了。动作是 `DoNothing`。

## 上架占位

`外观_上架占位` 只留 **填价 → 点确认/上架**：

- `enabled: false`。成功链不引用它。点第一件走 `外观_点第一个可寄售`，不走这个占位。
- `action` 是 `DoNothing`，没有点击坐标。
- **单次上限 6**。左侧标题是「出售道具 x/6」，空格写「空闲」。占位节点不读取 x/6，也不点击。

本版不填价、不点确认、不点上架按钮、不购买、不下架。

## 实机注记（1280×720）

燕云分身横屏。主菜单展开后，右侧功能格第二行左侧是「商店」（其上为「包裹」，其下为「不肝」）。点商店进入外观商城默认「推荐」。点「交易」后子页签为「外观推荐 / 珍品外观 / 武器外观 / 出售道具」。

出售页左右分开：

- **左侧**是已上架槽。标题「出售道具 x/6」，最多 6 格。空着时每格写「空闲」。空仓和「右侧已有 3 件可寄售」时，左侧都可以是 **0/6、六格全空闲**。
- **右侧**是待上架。标题「可寄售」。空仓正文是「暂无可寄售道具」。放入 3 件后，标题仍是「可寄售」，下面第一行 3 个图标、每个数量 1，其余格是空的；**道具名看不见**。右下有「交易记录」。

| 控件 | 识别 / 坐标 | 说明 |
| --- | --- | --- |
| 主菜单 | 模板 `storage/主菜单.png`，ROI `[1080, 0, 200, 90]`，阈值 0.75；兜底 `(1180, 45)` | 与存放相同图标 |
| 商店 | OCR「商店」，ROI `[740, 150, 480, 280]`；兜底 `(950, 270)` 再 `(848, 316)` | 菜单格子。两处坐标都盖在 ROI 内，优先 OCR |
| 交易 | OCR `^交易$`，ROI `[360, 0, 480, 90]`；兜底 `(590, 42)` | 商城顶栏 |
| 出售道具页签 | OCR「出售道具」，ROI `[400, 52, 500, 68]`；兜底 `(637, 97)` | 只点页签行。不包含左侧标题，也不包含右侧图标 |
| 出售页标题 | 成功判定里的 OCR「出售道具」，ROI `[160, 48, 740, 140]` | 页签和「出售道具 0/6」都算看见出售页 |
| 可寄售 / 空文案 | OCR「可寄售」或「暂无可寄售道具」，ROI `[900, 95, 360, 500]` | 只盖右侧栏。有图标时认标题；空仓认「暂无可寄售道具」 |
| 可寄售图标 | 第一件中心 `(1024, 208)` | 3 件截图第一行最左一枚。无道具名，只点这一下 |
| 上架面板 | OCR「上架」「单价」等，ROI `[200, 40, 1000, 640]` | 只认不点。文案待实机再收 |
| 返回（仅失败） | `medicine/返回.png`，ROI `[1125, 0, 145, 68]` | 只在进不了出售页时点一次 |

每步盲点 `max_hit` 为 1。某步认不到会在短超时后走 `on_error`，不会来回死点。

## 安全原则

- 不点「不肝」，不调用买钱节点。
- 有货时只点可寄售 **第一件** 一次。不点数量「1」、不点「交易记录」、不点购买。道具名图上没有，不要按名字点。
- 面板上的「确认」「上架」只允许被认到，不允许被点。不填价。
- 未知弹窗不盲点确定。导航失败最多点一次返回箭头，然后停住并失败。
- 还没到出售页不能结束。到了出售页之后，无货、无空位、或已经点过第一件，都是成功。

## 手动验证

仓库内的 `MFAAvalonia/` 被 gitignore，本机没有 MFA 时流水线无法在模拟器里点真机。接到 MFA 后：

1. `python tools/publish_mfa.py <MFAAvalonia目录>`（目录不存在会直接退出）。
2. **重启** MFAAvalonia.exe，让它重载 `interface.json`。资源选「官服」，控制器短边 720，连上燕云。
3. 人站在主界面（右上是主菜单，功能菜单未打开或已打开均可）。
4. 只勾选「外观上架」，开始。
5. 期望路径：主菜单 → **商店**（不要出现先点「不肝」）→ 顶栏 **交易** → **出售道具**。
6. 空仓（「暂无可寄售道具」）任务成功，**不要**点右侧空区。
7. 左侧 0/6 且右侧有 3 个图标：应点中 **第一件** 一次。若弹出详情或上架面板，任务成功并停在面板上。不应出现填价或点「确认 / 上架」。
8. 若左侧已是 6/6：不点右侧，任务成功。
