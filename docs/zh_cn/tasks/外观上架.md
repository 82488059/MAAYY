# 外观上架

本页说明界面任务「外观上架」。入口在 `assets/interface.json`，节点在 `assets/resource/pipeline/appear_list_task.json`，入口名 `外观上架`。无界面选项。可单独从主界面跑。不接入 [一条龙](一条龙.md)。

流水线协议见 [任务流水线协议](https://github.com/MaaXYZ/MaaFramework/blob/main/docs/zh_cn/3.1-%E4%BB%BB%E5%8A%A1%E6%B5%81%E6%B0%B4%E7%BA%BF%E5%8D%8F%E8%AE%AE.md)。坐标与 ROI 均按控制器缩放到短边 720 后的 **1280×720** 图计算。

> **实现状态**：流水线已落地（V2，连续多件）。空可寄售或无空位：回主界面后成功。有空位且第一格非空：**连续**点第一格 → **长按**减号直到 toast「价格已达最小」→ 点寄售 → 确认「上架成功」→ 回分流再下一件，直到满仓、没货或点第一格达上限 **6**；结束前回主界面。确认后继续**不依赖** OCR「空闲」（分流直接用第一格非空；「空闲」仅兜底）。降价**不依赖 Agent 比价**；失败收工仍用 `打印失败节点`（需 Agent）。空格图已入库；灰色减号图待补。

## 目标

从主界面走到燕云商城的 **出售道具** 页：

**主菜单 → 商店 → 交易 → 出售道具**

主菜单展开后直接点格子「商店」，进入外观商城（顶栏：推荐 / 外观 / 精选 / 月卡 / 和鸣 / 福利 / **交易** / 充值）。

到达出售页之后：

1. 右侧是「暂无可寄售道具」，或可寄售区第一格对得上空格模板：**回主界面** → 成功，不点道具。
2. 左侧已是「出售道具 6/6」，或看不见「空闲」：**回主界面** → 成功，不点道具。外观最多同时上架 **6** 个（左侧「出售道具 x/6」）。
3. 未满仓且第一格对不上空格模板：点 **第一个道具**（可不先认出「空闲」）。右下出现「单价/价格」和「寄售」后，**长按**价格旁的「−」，直到顶部 toast 出现「价格已达最小」，再点「寄售」，弹窗「上架成功」后点确认，回到分流继续下一件，直到满、没货或达上限 6 件。

有可寄售道具 = 可寄售区第一格不是空的。用空格子模板比对，不 OCR 道具名，也不认数量「1」。

舟3 实测放入 3 件时：左侧仍是「出售道具 0/6」、六格全是「空闲」；右侧「可寄售」第一行 3 个图标。左侧「空闲」是上架槽空位，不是「没有可寄售」。

## 前置

- 人在 **主界面**（大世界），右上能点开主菜单。已停在商城、交易或出售页时，入口从当前页接着走。
- 短边 720；中文 OCR 已就绪。
- 主菜单模板复用 `storage/主菜单.png`。回主界面与失败收场复用 `medicine/返回.png`。
- 可寄售空格模板 `appear/可寄售_空格.png`（文件 `assets/resource/image/appear/可寄售_空格.png`）。只裁一个空格子，比 ROI 略小，不带图标。图还没放进仓库时，空仓靠「暂无可寄售道具」收工。缺图时取反会把「对不上模板」当成有货；空文案若也没认到，可能点到空的第一格。不要用 `image/empty.png` 充数。
- 降价主路径**不需要** Agent 比价（无 `外观_降价重置` / `外观_降价一步`）。失败收工复用 `打印失败节点`（`agent/debug_action.py`）。Agent 没起来时，仅失败收工会受影响；正常上架循环可跑。

## 步骤

起点：主界面。入口 `next` 按「已经走到哪」从后往前认，命中即从该步继续。

1. 已在出售页：`外观_认出售成功` 为 `And`，两个子识别都命中才进入分流。出售页 OCR「出售道具」，ROI `[160, 48, 740, 140]`（子页签和左侧标题「出售道具 0/6」）。可寄售区 OCR「暂无可寄售道具」「暂无可寄售」或「可寄售」，ROI `[900, 95, 360, 500]`（只盖右侧栏）。交易页只有子页签、还没有右侧「可寄售」时，`And` 不成立，改去点「出售道具」。
2. 已能看见子页签「出售道具」：OCR 点击，ROI `[400, 52, 500, 68]`（只盖页签行，约 y 52–120）。认不到则盲点 `(637, 97)`，只点一次。
3. 已在商城（顶栏有「交易」）：OCR `^交易$`，ROI `[360, 0, 480, 90]`。认不到或点了仍不见「出售道具」，盲点 `(590, 42)`，只点一次。
4. 功能菜单已开（菜单区内同时有「商店」和「包裹 / 不肝 / 培养」之一）：不再点主菜单，直接点「商店」。
5. 否则点右上角 **主菜单**（模板 `storage/主菜单.png`，ROI `[1080, 0, 200, 90]`，阈值 0.75）。模板没有时盲点 `(1180, 45)`，只点一次。
6. OCR 点菜单里的 **商店**（ROI `[740, 150, 480, 280]`）。认不到则先盲点 `(950, 270)`，仍进不了商城再盲点 `(848, 316)`。两处都只点一次。两个盲点之后仍不见「交易」，改盲点顶栏 `(590, 42)`。
7. 认不到出售页则失败收场：右上有返回箭头（`medicine/返回.png`，ROI `[1125, 0, 145, 68]`）就点一次，然后 `外观_结束失败`（`打印失败节点`）。不循环点返回。
8. 分流（`外观_分流可寄售`，确认后也回到这里；同一张图上按顺序）：
   - OCR「暂无可寄售道具」/「暂无可寄售」/「无可寄售」（右侧栏 ROI 同上）→ **回主界面** → 成功。
   - OCR 标题「6/6」（ROI `[160, 100, 420, 80]`）→ **回主界面** → 成功。「0/6」对不上「6/6」。
   - 第一格模板匹配 `appear/可寄售_空格.png`，ROI `[988, 172, 72, 72]`，阈值 0.75 → 第一格是空的，**回主界面** → 成功。ROI 只包第一格。
   - 同一模板、同一 ROI，`inverse: true`（`外观_第一格非空`）→ 有可寄售，**直接**点第一格。确认后继续靠这条，避免 OCR「空闲」偶发漏识别早退。
   - OCR 左侧「空闲」（ROI `[160, 150, 740, 500]`，阈值 0.35）→ 兜底：再判第一格非空或直接点第一格。
   - 以上都没有 → 回主界面。
9. 点第一个道具：`外观_点第一个可寄售` 点击第一格中心 `(1024, 208)`，`max_hit` 为 **6**（连续上架安全上限；满/无货会更早停）。然后 `外观_认上架面板` 为 `And`：右下同时 OCR「单价」/「价格」与「寄售」。认到后降价；认不到仍进降价一轮（on_error）。
10. 降价（**长按 − + toast**，不连点、不同价）：
    - `外观_降价一轮` 先认 toast「价格已达最小」（ROI `[450, 80, 380, 65]`）→ 到底，去点寄售。
    - 或减号变灰：模板 `appear/价格减号_灰.png`（还没入库，**仅辅助**）。对上则到底。
    - 否则 `外观_长按减号`：`Swipe`，`begin`=`end`=`[1028, 579]`，`duration` **1800** ms，任务内合计最多 **48** 次（约 8 次/件 × 6 件）；每次后短等再回 `外观_降价一轮`。
    - 超限仍无 toast：`外观_降价失败`，**不点寄售**。禁止固定金额兜底；禁止「连续两次同价」作主判定。
11. 点「寄售」：优先实测坐标 `(1161, 678)`（`max_hit` 6）；点不到再 OCR `^寄售$`（`max_hit` 6）。然后等弹窗。
12. 弹窗 OCR「上架成功」（ROI `[400, 200, 480, 280]`）后点确认 `(1082, 474)`（`max_hit` 6，`post_delay` 1500），回到步骤 8 分流，继续下一件。
13. 回主界面（`外观_回主界面`，对齐存放_退出循环）：认出 `storage/主菜单.png`（ROI `[1080, 0, 200, 90]`）则停；否则点 `medicine/返回.png` 或盲点 `(1188, 32)`，循环几次，再 `外观_结束`。

## 实机注记（1280×720）

燕云分身横屏。主菜单展开后，右侧功能格第二行左侧是「商店」（其上为「包裹」，其下为「不肝」）。点商店进入外观商城默认「推荐」。点「交易」后子页签为「外观推荐 / 珍品外观 / 武器外观 / 出售道具」。

出售页左右分开。左侧是已上架槽，标题「出售道具 x/6」，最多 6 格，空着写「空闲」。右侧是待上架，标题「可寄售」；空仓正文是「暂无可寄售道具」。放入 3 件后标题仍是「可寄售」，第一行 3 个图标，道具名看不见。右下有「交易记录」。

舟3 已验证：长按减号到底会出现顶部 toast「价格已达最小」；寄售后弹窗「上架成功」可点确认。

## 安全原则

- 不点「不肝」，不调用买钱节点。
- 空可寄售（空文案，或第一格对上空格模板）回主界面再成功，不点右侧空区。
- 左侧已满 6 个（「6/6」）回主界面再成功。
- 未满且第一格非空时，连续处理可寄售第一格直到满、没货或达上限 6；不点数量「1」，不点「交易记录」，不点购买。确认后回环不强制 OCR「空闲」。
- 先长按降到最低再点「寄售」。到底的主判定是 toast「价格已达最小」。灰减号仅辅助。禁止同价 OCR、禁止固定金额兜底。
- 减号长按任务内合计最多 48 次。到上限仍无 toast：失败，不点寄售。
- 「寄售」只在到底之后点。降价过程中不点它。上架成功后必须点确认，再回分流。
- 未知弹窗不盲点确定（上架成功确认坐标已实测除外）。导航失败最多点一次返回箭头，然后停住并失败。
- 成功路径结束前必须尽量回到主界面。还没到出售页不能当成功结束。
