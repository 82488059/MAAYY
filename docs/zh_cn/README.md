## 任务专文

玩法说明在 [`tasks/`](tasks/)。**MFA 主界面默认顺序**与 `assets/interface.json` 的 `task` 一致，完整表见 [项目概览 · 界面任务](项目概览.md) 与 [tasks/README](tasks/README.md)。

当前顺序：无限水井 → 无限太极 → 无限集英 → 每日号令 → 自动天工 → 一条龙 → 存放原料 → 自动买药 → 自动炼药 → 自动买钱 → 离开百业 → 返回百业 → 找温无双 → 退出游戏 → 修改为地基模式。

| 文档 | 内容 |
| --- | --- |
| [一条龙](tasks/一条龙.md) | 可勾选步骤的总入口：买药→离开→炼药→钱袋→返回→找温→退出 |
| [存放原料](tasks/存放原料.md) | 原料入仓库，草药与枯茱萸留下 |
| [自动买药](tasks/自动买药.md) | 货运买草药/枯茱萸，必要时先存放 |
| [离开百业](tasks/离开百业.md) | 驻地退出到主界面 |
| [自动炼药](tasks/自动炼药.md) | 逍遥散循环炼药（需 Agent） |
| [自动天工](tasks/自动天工.md) | 天工道具 checkbox 多选合成（不耗体力） |
| [自动买钱](tasks/自动买钱.md) | 金丝钱袋与通宝（需 Agent） |
| [返回百业](tasks/返回百业.md) | 主界面回驻地 |
| [找温无双](tasks/找温无双.md) | 回驻地后走到温无双旁 |
| [退出游戏](tasks/退出游戏.md) | 一条龙找温后收尾（暂空转） |
| [无限集英](tasks/无限集英.md) | 循环点「集英」；齿轮填点后等待秒数（需 Agent） |
